### About

- **Building:** browser-based 3D worlds, accessibility tools for schools, and a mental-health platform designed so even its own admin cannot read user data.
- **Working with:** JavaScript, React / Next.js, Three.js, Supabase, and applied NLP and speech models.
- **Approach:** correct first, honest about limits, no invented numbers. I report what was tested and what was not.
- **Goal:** to grow into a professional creative technologist, building software with real users.

### Featured projects

| Project | What it is | Stack | Links |
|---|---|---|---|
| **SuaraPapan** | Speech-to-scene classroom tool for students with disabilities. A teacher speaks in Indonesian; captions and an interactive illustrated scene appear on the projector. Built for the UGM FMIPA 2026 hackathon. | React, fine-tuned IndoBERT (NER), Gemini, Vercel | [Live](https://suarapapan.vercel.app) · [Code](https://github.com/Atatron/suarapapan) |
| **Galeri Sekolah** | A walkable 3D virtual museum platform for schools. Each school curates its own collection and visitors walk the hall in first person. | Three.js, Supabase (RLS, Realtime), vanilla ES modules | [Code](https://github.com/Atatron/galeri-sekolah) |
| **KATASHA** | Mental-health support platform with an encrypted diary, real-time psychologist sessions, and walkable 3D library and cinema rooms. Privacy is structural: the admin cannot read user data. | Next.js, Supabase, React Three Fiber, Tailwind | Private (competition build) |
| **VoxelCraft** | A Minecraft-style voxel game written from scratch, with creative and survival modes. Every texture is painted in code and every sound is synthesised, so no third-party assets are used. | Three.js, Web Workers, WebGL2 | [Play](https://voxelcraft-nu.vercel.app) |
| **Primeval Isles** | Dinosaur survival game across a procedural archipelago. Shipped as a browser world, now being rebuilt in Unreal Engine 5 for photoreal creatures. | Three.js, then Unreal Engine 5 (C++) | [Play browser version](https://primeval-isles.vercel.app) |
